# Multi-Agent Interview Platform

An AI-powered platform for personalized interview preparation,
answer evaluation, and learning roadmap generation.

## Project Overview

The platform uses specialized AI agents to help candidates
practice interviews and improve their skills.

## AI Agents

- Resume Agent
- HR Agent
- Technical Agent
- Coding Agent
- AI Feedback Agent
- Roadmap Agent

An Interview Orchestrator coordinates the interview workflow.

## Technology Stack

### Frontend
- React.js

### Backend
- Python
- FastAPI

### AI
- LangChain
- LangGraph

### Database and Caching
- MongoDB Atlas
- Redis

### Infrastructure
- Microservices
- Docker
- AWS

## Main Features

- Secure user authentication
- AI-powered resume analysis
- HR, technical, and coding interviews
- Automated answer feedback
- Personalized learning roadmap
- Modern user dashboard
